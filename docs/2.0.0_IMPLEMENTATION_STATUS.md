# ChessBuddy 2.0.0 implementation status

The downloadable 2.0.0 rebuild source package contains a refreshed local-first lobby, 16 bundled original portrait assets with deterministic bot mapping, Android versionName 2.0.0, and a startup/home smoke test.

Local verification: all logic tests pass; Java policy tests pass; app.js syntax passes; compressed source ZIP integrity passes and the archive is under 50 MB.

Not release-certified: Android APK build/install, physical-device UI/voice/animation tests, browser screenshot suite (Playwright unavailable), live Supabase OAuth/email recovery/profile flow, live Lichess calls, and two-device multiplayer. These require Android CI, device testing, and live configured services. This is a rebuild candidate, not a finished production release.

The rebuild intentionally uses an original ChessBuddy interface and artwork. It does not claim to be an exact Chess.com clone or to reproduce proprietary Chess.com bot behavior/ratings.
